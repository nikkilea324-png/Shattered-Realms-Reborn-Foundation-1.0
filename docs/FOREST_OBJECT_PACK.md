# Shattered Realms: Reborn — Forest Object Pack 1.0

## Purpose

This pack is the first exportable production-asset pass derived from the approved Forest Object Pack visual target.

The target language is:
- chunky stylized low-poly geometry
- hand-painted color blocking
- strong readable silhouettes
- modular hex terrain
- dark-fantasy forest palette
- Godot 4.7+ / GLB delivery

## Runtime format

Assets are delivered as individual .glb files so Godot can import them independently and instance them throughout the world.

Recommended project location:

res://assets/forest_pack/glb/

## Important status

This is an exportable geometry pack, not the final texture-heavy asset generation stage. The geometry intentionally follows the approved stylized reference and is suitable for replacing the current procedural proof objects.

The next asset pass can add:
- richer surface geometry
- authored 2K PBR textures
- LOD tiers
- collision meshes
- optimized material atlases
- named attachment/origin metadata
- production-ready Godot scenes

Do not replace the rendering proof camera or scale contract while integrating these assets.
